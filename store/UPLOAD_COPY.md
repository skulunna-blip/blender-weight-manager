## English Description (327 chars, safe)

```
Precise C4D/Maya-style weight painting panel for Blender, in a side panel. Drag weight sliders (Absolute / Add / Subtract / Smooth), mirror and copy/paste, normalize, edit every bone in a per-vertex weight table, select by weight, live HUD, and edge-loop picking in Weight Paint mode. Blender 4.2+, Edit and Weight Paint modes.
```
