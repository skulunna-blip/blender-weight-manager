# Weight Manager 权重管理器 · 零基础使用教程

> 面向"完全没刷过权重"的新手。每个概念都先用大白话讲清楚，再告诉你怎么点。
> 内容顺序：先懂概念 → 装好 → 第一次上手 → 逐个功能 → 实战流程 → 疑难解答。

---

## 第 0 步：一分钟搞懂"权重"是什么

3D 角色怎么动？靠的是"骨头带动皮"：

```
        骨头（骨骼/Bone）             皮（网格/Mesh）
     ┌───────────────┐          ┌───────────────┐
     │    肩 骨       │          │  一堆小三角面  │
     │    肘 骨       │  =======>│  （由许多顶点  │
     │    腕 骨       │  分配     │   组成）      │
     └───────────────┘          └───────────────┘
```

模型是一张"皮"，由很多很多**顶点**（网格上的小点）组成。顶点自己不会动，它得听骨骼的。**权重**就是一张分配表，写着"这个顶点听哪根骨头、各听多少"。

- 权重用 0.0 ~ 1.0 的数字表示。**0 = 这根骨头完全不管这个点；1 = 这根骨头全权管这个点**。
- 一个点可以被好几根骨头管，比如"手肘内侧的点 = 上臂骨 60% + 前臂骨 40%"，这样手肘弯起来才自然（关节处的皮不会断裂）。
- 每个顶点的**所有权重加起来 = 1**（这叫"归一化"）。上面那个点 0.6 + 0.4 = 1。

**顶点组（Vertex Group）** 在 Blender 里就是"一根骨头管着的点的名单 + 每个点管多少"。所以面板里的"顶点组列表"= 骨骼列表。改权重，本质就是改这张分配表。

> 一句话：**刷权重 = 决定"模型每个点归哪根骨头管、管多狠"。** 刷得好，角色动画自然；刷得乱，动起来皮会撕裂、会乱扭。

## 第 1 步：安装

有两种方式，**普通 addon** 和**官方扩展**，任选其一。

### 方式 A：普通插件（zip）
1. 打开 Blender → 顶部菜单 `Edit`（编辑）→ `Preferences`（偏好设置）→ `Add-ons`（插件）
2. 点右上角 `Install…`，选 `weight_manager.zip`
3. 在搜索框输入 `weight manager`，勾选 **"Mesh: Weight Manager (权重管理器)"**

### 方式 B：官方扩展（推荐，4.2 及以上）
1. 打开 Blender → `Edit` → `Preferences` → `Get Extensions`（或 `Add-ons` 里的下拉选 **Extensions**）
2. 点 `Install from Disk…`，选 `weight_manager.zip`（扩展版，根目录是 `blender_manifest.toml` 的那个）
3. 勾选启用 **Weight Manager (权重管理器)**

> 装完后：3D 视口里按 **`N`** 打开右侧侧栏，会看到多出一个 **Weight Mgr** 标签——这就是本插件的家。

## 第 2 步：打开面板前的准备工作

面板只对"网格物体"显示，并且大部分功能要进入**编辑模式**或**权重绘制模式**才生效。

1. 选中一个网格物体（比如默认的立方体）
2. 面板出现 **Weight Mgr** 标签，点进去
3. 现在你看到"顶点组（骨骼）"列表是空的——正常，先造几根"骨头"

## 第 3 步：第一次上手（跟着做 5 步就入门）

我们用默认立方体演示。

### ① 造两根"骨头"
在面板「顶点组（骨骼）」区域，点 **新建**，输入名字，比如 `Bone_Left`；再建一个 `Bone_Right`。
（在真正的角色上，这些顶点组会由"自动权重绑定骨骼"自动生成，不用手搓——这里只是方便你理解。）

### ② 进入权重绘制模式
用快捷键 `Ctrl+Tab`，在弹出的菜单里选 **Weight Paint（权重绘制）**。
或者点视口左上角的模式下拉框 → 选 **权重绘制**。

### ③ 把"点"分给骨头
- 默认当前组是 `Bone_Left`。鼠标放到网格上，按住 **左键拖动** 开始涂——涂过的地方变成橙黄色，说明"这些点归 Bone_Left 管了"。
- 想涂右边：面板里「对称」开 **X**（左右镜像），或者干脆刷完左边再用面板刷右边。

### ④ 用"条"精确设值（本插件的主打，对标 C4D）
1. 进入**编辑模式**（`Tab` 键）
2. **框选（`B`）**几个顶点，或者 **`A`** 全选
3. 面板「Auto Weight」里选 **Absolute**（最左边那个）
4. 拖动下面的大条到 **50%**——选中点立刻全部变成 0.50，旁边数字实时变化

> 这就是 C4D 权重管理器最核心的交互：**不用笔刷乱涂，用拉条精确到小数。**

### ⑤ 看一眼每个点的数字
1. 编辑模式下选中 1~3 个顶点
2. 面板最下面出现「**顶点权重表**」
3. 上面列表是选中的点，点选切换；下面列表显示**所有骨头**在这个点的权重数字，**拖动滑条直接改**。

## 第 4 步：面板每一块怎么用（按顺序从上到下）

### ① 顶点组（骨骼）列表 —— 谁是当前"骨头"
- 点哪一行，哪一行就是当前组，后面所有操作都作用在它身上。
- 每行右侧有个小**百分比条**：显示"当前选中点在这根骨头上的平均权重"，一眼看出这根骨头盖住了多少。
- 行尾的**锁图标（🔒）**：点一下就锁定。**锁定的组只读**，Normalize 归一化时它不会被改动（对标 C4D 的"锁关节归一化"）。
- 下面的按钮：**新建 / 删除 / 重命名**。

### ② 影响范围高亮 —— 一根骨头管了哪些点
- 开关「高亮当前组影响范围」默认开。在编辑/权重绘制模式下，点选一根骨头，视口会把它管到的点（权重>0）用**橙色点**标出来。
- 刷权重前先看一眼，避免"这根骨头连到不该管的点上"。

### ③ Joint Filter 关节过滤器 —— 骨头太多看不清
- 勾选「仅显示影响选中点的关节」：列表只留下"在选中点上有权重的骨头"，无关骨骼全藏起来。
- 「搜索骨骼名」框：按名字过滤。两者可叠加。

### ④ 权重 HUD —— 鼠标指到哪，数值跟到哪
- 勾选「权重 HUD（光标权重值）」。编辑/权重绘制模式下，鼠标移到网格上，光标旁会实时显示 `骨头名: 权重值`。
- 对标 C4D 的视口 HUD，刷的时候不用低头看面板。

### ⑤ 选择遮罩 + 对称（权重绘制模式顶部）
- **面遮罩 / 点遮罩**：Blender 权重模式下默认看不见线框、也框选不了点。开了这俩开关才能看线框、框选/点选。**点遮罩**下未选中的点会变黑（正常现象，先框选再刷）；嫌黑就用**面遮罩**（未选中面只是变暗）。
  - 快捷键：**Alt+左键** 选面、**Shift+Alt** 加选、**B** 框选、**A** 全选。
- **对称 X/Y/Z**：开了后，权重笔刷刷左边、右边自动跟着动（对标 C4D 对称刷）。

### ⑥ Auto Weight —— 核心刷权重区
选一个模式，然后拖动下面的大条（或把鼠标悬停在条的数值上按 **Ctrl+滚轮**）：
- **Absolute（绝对）**：条拖到哪，选中点权重**直接变成**那个值。点哪跳到哪。
- **Add（叠加）/ Subtract（叠减）**：条拖多远就**加/减多少**，方向不影响、只看拖动的幅度。松开后条自动归零，可以反复拖、反复叠。
- **Smooth（平滑）**：条拖多远就把选中点的权重往邻居的平均值**靠多少**；**平滑半径**（1~5）越大，影响范围越大、越平滑。
- 「应用一次（按 Strength）」：不想拖条？设好 Strength 直接按一次。

> 提示：**Ctrl+滚轮** 微调数字/条是 Blender 原生行为。裸滚轮不反应是正常的。

### ⑦ Commands —— 反悔、镜像、复制黏贴
- **反转**：1 − 权重（白变黑、黑变白，适合"把没刷的地方刷上"）。
- **镜像**：把选中点的权重复制到对称位置（选 X/Y/Z 轴）。**左右不对称的模型镜像前先确认轴**。
- **复制权重 / 黏贴权重**（对标 C4D）：
  1. 选中一组点，按**复制权重**（把当前骨头在这些点上的值记下来）
  2. 换选另一组点（或换一根骨头再选点），按**黏贴权重**
  3. 按选中顺序一一对应贴上去；点数不一致时只贴前几个（有提示）。

### ⑧ Normalize 归一化 —— 让总和等于 1
- 选中点 → 按「归一化选中点（总和=1）」。
- **锁定的组（🔒）权重保持不动**，只调其余组的比例补足总和。
- 什么时候用：手抖刷超了 1、或者用 Absolute 把某些点刷成"总和>1"，动画会跳——归一下就好了。

### ⑨ 按权重选择 —— 快速抓取"某种权重"的点
- `=0`（完全没权重）、`>0`（有一点点）、`<1`（不全权）、`=1`（全权管）、`≈区间`（阈值附近的）。
- 比如想找"忘了刷上的点"→ 按 `=0`。

### ⑩ 顶点权重表 —— 像 Excel 一样看/改每个点的数字
- 编辑/权重模式下选中顶点后出现。
- 上列表：选中的点（点哪行切哪个点）；下列表：**所有骨头**在该点的权重，**按大小降序，0 在最底**。
- 拖某行滑条 = 直接改这个点在这根骨头上的权重。**把 0 拖大 = 给这个点加这根骨头**。
- 锁定的骨头行整行置灰，拖不动。

### ⑪ 填充选择 —— 配合 Fill Select 插件
- 需要另装「Fill Select 填充选择」插件（`bl_ext.fill_select_between`）。
- 用法：选中两条"边界环" → 按「填充选择」→ 两条环之间的面被选中 → 拖条刷权重。
- 专门解决"给腰带/袖口区域均匀刷权重"这种需求。

## 第 5 步：一个完整的实战流程（给角色手臂刷权重）

1. **绑定好骨骼、点好自动权重**（`Ctrl+P` → With Automatic Weights），此时 Blender 已把网格按骨骼自动分好了顶点组。
2. 进入**权重绘制模式**，选中要查的骨头（在面板列表点它），看橙色高亮点：这跟骨头管了哪些点、管得对不对。
3. **精细调整**：进入编辑模式 → 框选要改的区域 → 在 Auto Weight 用 Absolute 条把数值拖到想要的百分比。
4. **处理关节**：手肘内侧选一圈点，确认是"上臂+前臂各一半"（在顶点权重表里看两行的数字，拖滑条调到各 0.5）。
5. **发现某根骨头管多了**：选中不该管的点 → Auto Weight 把权重拖到 0（或按 `=0` 选中再归零）。
6. **左右要一样**：刷完左边，用 Commands 的**镜像**复制到右边。
7. **总和不对/动画乱跳**：选中全部点 → Normalize 归一化。
8. 播放动画检查，哪里撕裂就回第 3 步再调。

## 第 6 步：常见问题（FAQ）

**Q：面板是灰的 / 按钮按不了？**
A：需要**进入编辑模式或权重绘制模式**（`Tab` 或 `Ctrl+Tab`），并且选中了网格物体。

**Q：权重模式下整片是黑的？**
A：这是**点遮罩**开启的正常现象——未选中的点显示为黑。先框选（`B`）或点选（Alt+左键）顶点，选中区才显示颜色。嫌黑看不清就改开**面遮罩**。

**Q：滚轮转数值没反应？**
A：要按 **Ctrl+滚轮**（悬停在数值/条上）。裸滚轮是 Blender 原生不响应的。

**Q：列表里没有骨骼？**
A：还没建顶点组。在「顶点组」区域点**新建**；或先给角色 `Ctrl+P` 自动权重绑定，绑定后会自动生成骨骼的顶点组。

**Q：刷不上去 / 权重不变化？**
A：看是不是**锁定了**（行尾🔒）。锁定组只读，解锁再刷。另外检查当前选中的是不是你要刷的那根骨头。

**Q：顶点权重表不出现？**
A：要**编辑模式或权重绘制模式** + **选中了顶点**。两个条件都要满足。

**Q：Smooth 半径设了没用？**
A：半径 1 = 只取直接相邻的点；想一次平滑更大范围，把半径调到 2/3 再拖条。

**Q：换了 Blender 版本插件没了？**
A：每个 Blender 版本用独立的插件目录。把 `weight_manager` 文件夹复制到对应版本的 scripts/addons（或用新版本的 Install 重新装 zip）。官方扩展版同理：用新版本的"从磁盘安装"装一次。

## 附：和 C4D / Maya 的对应关系

| 本插件 | 对标软件 |
|---|---|
| 顶点组（骨骼）列表 | C4D Weight Manager 的 Joints 列表 |
| Auto Weight 拉条 | C4D Weight Manager 的 Auto Weight |
| 复制/黏贴权重 | C4D 的 Copy / Paste |
| Normalize + 锁定组 | C4D 的锁关节归一化 |
| 影响范围高亮、权重 HUD | C4D 点关节显示影响范围 / 权重 HUD |
| 顶点权重表（逐点看所有骨骼数字、可改） | Maya 的 Component Editor（更接近 Excel 表格） |
| 按权重选择 | C4D 的 Fill Selection |

> 一句话总结：**C4D 的"面板拉条刷权重"体验 + Maya 的"逐点看数字改权重"精确性，打包成一个 Blender 侧栏插件。**
